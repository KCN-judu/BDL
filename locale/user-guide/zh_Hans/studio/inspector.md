# 检查器

检查器（右侧）以分区表单的形式、用设计师的词汇显示选中的对象。每个字段都是编译器接受的一次编辑；检查器里没有装饰。没有选中任何东西时，它会说明可以选什么。

各分区下方，**最后一次更改**用一句关于 _其他_ 对象的话说明你最近一次编辑的后果——_没有其他需要重新检查的。_ 或 _此更改影响 dimByTilt、warmPulse；它们将被重新检查。_——而折叠的**解释**保存着形式化细节。

## 概念

| 分区 | 字段 | 说明 |
| ----------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **含义** | 名称、含义 |  |
| **值** | 量 / 开/关 / 计数 / 稍后决定；单位（量的种类列表，符号在单独一列） | 第一次选择值形式不会重新检查任何东西；更改已选的值形式会说明它重新检查哪些关系 |
| **关系** | _生成者_、_使用者_ | 名字是选中该关系的链接 |
| **删除 …** |  | 使用中时禁用；使用者列在按钮下方 |

## 关系

| 分区 | 字段 | 说明 |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------- |
| **含义** | 名称、含义、_角色_——_来源_、_关系_，或它所支撑的端口；来源会多一句说明 | 角色从设计中读出，从不设置 |
| **读取** | 带概念图形符号的标签，可移除；一个用于添加的弹出菜单 | 一次编辑；依赖项会被重新检查 |
| **生成** | 带图形符号的弹出菜单——对于来源，标题为**提供** | 一次编辑 |
| **关系** | 公式字段及其结论行；_添加定义_ / _保存定义_ / _还原_ / _分离定义_；字段下方的发现项；对于来源，字段上方是 _实现：由环境提供；尚未绑定设备。_ | 见 [公式编辑器](formula-editor.md) |
| **时序** | _更新于_——一个域，或 _任意时序域_；时序发现项 | 见 [时序](../../../../docs/user-guide/concepts/timing.md) |
| **驱动** | 这个值驱动的输出，或无；连接发现项 | 只有没有输入的关系才能驱动 |
| **修复** | 工具针对该关系的发现项提供的操作：就绪时是按钮，需要选择时是弹出菜单，受阻时显示原因 | 作为普通的、可撤销的编辑应用 |
| **删除 …** |  |  |

关系还可能显示 _属于组 …_ 及 _显示组_ 链接；绑定到端口时显示 _从 … 取值_ 及 _显示绑定_（附有 _断开它以自行定义该关系。_）；在组件的来源中，显示它支撑的端口（_requires_ / _provides_ / _parameter_）。端口在组件自己的检查器中声明。

**来源**——不读取任何东西且没有公式的关系——以同样的方式检查。它的角色一行写着 _来源_；它的输出部分是 _提供_；它的关系部分说明该值由环境提供、尚未绑定设备，并保留公式字段：添加一个公式，同一个关系就改为在设计内部计算。这里没有任何地方说 _传感器_ 或指名某个零件——由哪个设备提供这个值是在[部署页](deploy.md)上决定的，而今天还没有任何设备种类能提供。

## 时序域

时序域没有检查器页面：在侧栏中原地重命名，未使用时也在那里删除。它们的含义体现在 _更新于_ 它们的关系和输出中。

## 行为、组件、实例、绑定

它们有各自的检查器；[系统项目](../../../../docs/user-guide/studio/system-projects.md) 会描述它们。

## 解释

每个检查器末尾的展开区。它显示对象的标识号、形式化接口，对于有公式的关系还有推断出的类型和 Core 项；状态词；每个发现项背后的诊断代码和技术文本；修订号；以及最后一次更改的种类（_精化_ / _编辑_）和它使什么失效。这是 Studio 中唯一出现编译器词汇的地方。它上面的内容没有任何东西依赖它。
