# 工作区

Studio 有两个界面：**项目管理器**（没有打开项目）和**工作区**（打开了项目）。工作区是一个窗口，底部按工作流顺序排列着各个页面。

![The Studio window at 1440 by 900: the toolbar with the project name tilt-lamp, undo, redo, Save and Close; the Project sidebar on the left listing Concepts, Mappings, Timing domains, Outputs, Contexts and Components; the canvas in the middle with the tilt lamp's nodes; the inspector on the right showing the selected relationship brightness with its Meaning, Reads, Produces, Relationship, Timing and Drives sections; the status line reading Saved, 2 concepts, 3 mappings, 1 source, Compiler 0.1.0; and the page bar with Design, Simulate, Deploy and Monitor.](../../../../docs/user-guide/assets/studio/workspace.png)

_打开倾角灯并选中 brightness 的工作区：工具栏、侧栏、画布、检查器、状态行和页面栏。_

## 区域

**工具栏**——项目名称（有未保存更改时后面跟着 _已编辑_）、撤销和重做、保存（仅在已编辑时可用）和关闭。

**侧栏**（左侧）——在设计页有两个标签页：**项目**，按种类列出项目的对象（_概念_、_映射_、_时序域_、_输出_、_组件_、_实例_、_行为_），每一类都有 **+** 用于创建——_上下文_ 标题保持为空（上下文尚未进入工具）；以及**库**，现成的概念模板。见 [库](../../../../docs/user-guide/studio/library.md)。仿真页和部署页把它们自己的控件放在这里。

**页面内容**（中间）——设计页的画布、仿真页的轨迹、部署页的结论。

**检查器**（右侧）——选中的对象：它的含义、你能改什么、改动影响什么。见 [检查器](inspector.md)。

**状态行**——文档状态（_已保存_ / _已编辑_），然后是计数（_2 个概念_、_3 个映射_，以及当设计中有由环境提供的关系时的 _1 个来源_），然后是仍未完成的事项（_1 个尚未定义_、_输出未完成_、_存在瞬时环路_、_跨域读取_、_N 个定义尚未添加_），然后是编译器连接。来源本身就是完整的，所以它被计数，从不列为未完成。被拒绝操作的错误以**横幅**的形式出现在页面内容上方，带有 _关闭_ 链接——从不使用对话框。

**页面栏**——各个页面，按你使用它们的顺序：

| 页面 | 回答 | 快捷键 |
| ------------ | --------------------------------------------------------------------------------------------- | -------- |
| **设计** | 产品做什么 | ⌘1 |
| **仿真** | 它随时间做什么 | ⌘2 |
| **部署** | 它能放进这块板子吗 | ⌘3 |
| **监视** | 它现在正在做什么——_尚未构建_；页面说明实时值将随遥测功能一起到来 | ⌘4 |

页面栏左侧的按钮（⊞）关闭项目并返回项目管理器。右侧的齿轮打开**偏好设置…**：Studio 使用的语言（跟随系统、English、简体中文、日本語），它只改变 Studio 显示的内容——从不改变 BDL 源码、项目文件或编译器。项目管理器上也有同样的链接。

## 保存、撤销、修订

**⌘S** 或**保存**把整个项目写入它的文件夹——设计、布局，以及每一个未完成的编辑：已输入但未添加的公式、代码视图中尚不能构建的文本。设计改动会记录为项目的一个新 _修订_；**⌘Z** / **⇧⌘Z** 在它们之间前后移动。移动节点、调整面板大小和折叠分组不是设计改动：它们会被保存，但不产生修订。已输入但未添加的公式是一份 _草稿_——切换选择或页面时会保留，随项目一起保存，在你添加或还原之前，状态行把它计为 _定义未添加_。

## 关闭项目

**关闭**、项目管理器按钮（⊞）、**⌘W**、**⌘Q**、菜单中的退出、窗口的关闭按钮，以及打开或创建另一个项目，在项目与已保存内容不同时都会问同一个问题：

> 是否保存对“lamp”的更改？**不保存** · **取消** · **保存**

**保存**原样保存一切然后关闭；如果保存被拒绝（有文件在磁盘上被修改——见横幅），项目保持打开。**不保存**直接关闭；下次打开回到上次保存的状态。**取消**（Esc）什么都不改。_已保存_ 的项目立即关闭。不会问两次，问题未回答时也不会关闭任何东西。

## 三个信息层次

Studio 在三个层次上展示设计，并把它们分开：

1. **画布**——看得见的结构：形状、颜色、连线、虚线轮廓、红色标记。没有类型名，没有标识符。
2. **检查器**——设计师的词汇：_含义_、_值_、_读取_、_生成_、_更新于_、_驱动_；用产品语言写的发现项，紧挨着它们涉及的字段。
3. **解释**——每个检查器末尾一个折叠的展开区：标识号、形式化接口和项、诊断代码、修订号。前两个层次没有任何东西依赖它。

本指南遵循同样的顺序：解释画布和检查器，其余的指向 _解释_ 和技术文档。
