# インストールと起動

Behavior Designer はソースからビルドします。インストーラやパッケージ化されたダウンロードはまだありません。ビルドは 2 つのものを生成します。Studio アプリと、それが通信するコンパイラサービス（`bdld`）です。後者は Studio が起動します。

## 必要なもの

| ツール | バージョン | 備考 |
| ------- | ------------------------------------------------------ | ------------------------------------------------------ |
| Rust | 1.89 — リポジトリで固定、`rustup` でインストール | コンパイラサービスをビルドする |
| Flutter | 3.47 | Studio をビルドする。macOS では `brew install --cask flutter` |
| `just` | 任意 | リポジトリが使うタスクランナー |

サポートされるデスクトップは macOS と Windows です。Linux は副産物としてビルドできますが、検証されていません。

## ビルドと実行

リポジトリのルートで：

```bash
just studio
```

これで `bdld` をビルドし、それを指す Studio を起動します。最初のビルドには数分かかりますが、その後は速くなります。

**ターミナルか Finder から起動したシェルで実行してください**。他のアプリケーションに埋め込まれたターミナルからは実行しないでください。macOS はサンドボックス化されたホストから起動されたアプリにファイルダイアログを表示しません。Studio はそれを検出してパス入力（_パスを指定して開く…_、_パスを指定して新規作成…_）を代わりに提供しますが、ネイティブのダイアログが本来の方法です。

## 最初に見えるもの

Studio は**プロジェクトマネージャー**で開きます。左にワードマーク、その下に _開始_ の操作、右に _最近_ のプロジェクトです。

![Studio's start screen with New Project and Open Project buttons on the left and an empty Recent list on the right; the status line at the bottom says no project and names the compiler version.](../../../../docs/user-guide/assets/getting-started/project-manager.png)

_プロジェクトマネージャー：左に開始の操作、右に最近のプロジェクト。_

| 操作 | 動作 |
| ----------------- | --------------------------------------------------------------------------------- |
| **新規プロジェクト…** | フォルダ名と場所を尋ね、そこにプロジェクトを作成し、ワークスペースを開く |
| **プロジェクトを開く…** | 既存のプロジェクトフォルダを開く |
| _最近_ の行 | そのプロジェクトを再び開く。フォルダがなくなった行はグレーで _見つかりません_ と表示される |

**プロジェクト**はフォルダです。その中のすべてはプレーンなファイルとして保存されます（[プロジェクトファイル](../reference/project-files.md)）。設計はコードエディタでも編集できる `.bdl` テキストとして、その横にキャンバスのレイアウトが保存されます。プロジェクトの種類は 1 つだけで、振る舞いグループ、コンポーネント、インスタンス（[システムプロジェクト](../../../../docs/user-guide/studio/system-projects.md)）と**コード**ビュー（[設計・コード・分割](../studio/code-view.md)）はどのプロジェクトでも使えます。

ウィンドウの最下行はコンパイラサービスとの接続を示します。接続中は _コンパイラ 0.1.0_、起動中は _コンパイラに接続中_、失敗した場合は _コンパイラ未接続_ です。Studio は自分では意味的な処理を何もしません——ガイドのすべての検査、値、判定はそのサービスから来ます——ので、アプリが反応しないように見えたら、まずこの行を見てください。

## 完成した例を試す

リポジトリには完成したプロジェクトが 1 つ、`examples/smart_lamp` として同梱されています。_プロジェクトを開く…_ → そのフォルダを選びます。これはチュートリアルで作るランプに環境光センサーを加えたもので、入力 2 つ、関係 3 つ、必須出力 1 つ、PWM デバイス 1 つです。自分のものを作る前に、その設計・シミュレート・デプロイの各ページを見て回れます。
