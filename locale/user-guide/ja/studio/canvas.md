# キャンバス

キャンバスは設計ページの中央で、設計の構造の絵です。その上のすべてに意味があり、各視覚チャネルはただ 1 つのことを意味します。

## 印の意味

| 見えるもの | 意味 |
| -------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ソケットの色** | _どのコンセプトか_——各コンセプトは固有の色相を持ち、現れる場所すべてで同じ |
| **ソケットの形** | コンセプトの _値の形式_：○ 量、◇ オン/オフ、□ 個数。値の形式が _後で決める_ の間は**中空の輪** |
| **リンク** | _この関係はそのコンセプトを読み取る_（コンセプト → 関係の入力）、または _この値はその出力を駆動する_（関係 → シンク） |
| **破線の輪郭** | _宣言済み_：何かを読み取るが数式のない関係。駆動元のない、またはドメインのない出力 |
| **ノード左端の縦バー、入る矢印、_入力元_ の語** | **入力元**：環境から与えられる値——何も読み取らず数式を持たない関係。欠けているものは何もない |
| **数式行の赤い印** | 数式が検査を通らない——_今、間違っている_ のであって、_まだ_ ではない |
| **_宣言済み_、_競合_、_不正_、_ドメインなし_ の語** | ノードが持ちうる唯一の状態語。その状態が成り立つ間だけ（駆動されなければならない出力はその間 _必須_ と表示され、入力元は _入力元_ と表示される） |
| **ノード右端の小さな名前** | そのタイミングドメイン |
| **アクセントカラー** | 選択——それ以外にはない |

位置、大きさ、リンクの向きに**意味はありません**。データは読みやすさのために左から右へ描かれます。辺は依存を示し、何かが実行される順序ではありません。演算子ごとのノードはなく、算術は数式フィールドにあります。

## ノード

![Concept rows Tilt and Brightness with a round socket at each end; relationship nodes with a name header, one input socket per concept read on the left, one output socket on the right and the formula in the body; dimByTilt outlined in the accent colour because it is selected; the Source tilt with a bar at its left edge, an entry arrow and the word Source in its header and no input socket; the light sink at the right with the word required in its header, a single input socket and a bar at its right edge; tilt, brightness and the output carry the domain name interaction at their right edge.](../../../../docs/user-guide/assets/studio/node-anatomy.png)

_傾きランプのノードの構造：コンセプト行、関係ノード（dimByTilt を選択）、light シンク。_

**コンセプト**は 1 行です。名前、左の入力ソケット（何かがこのコンセプトを生成する）、右の出力ソケット（関係はここから読み取る）。両方のソケットがコンセプトの色と形を持ちます。

**関係**は箱です。名前と、該当する間だけ唯一の状態語（何かを読み取るがまだ数式のない関係には _宣言済み_）を持つヘッダー。左に読み取るコンセプトごとに 1 つの入力ソケット（それぞれコンセプト名付き）。右に生成するコンセプト名付きの出力ソケット 1 つ。その下の行に数式、関係がタイミングドメインを持つときは右端にその名前。何も読み取らない関係——上の `brightness`——には入力ソケットがありません。それは値であり、その数式が依存する値と規則を名指しします。

**入力元**は、何も読み取らず数式を持たない関係です——上の `tilt`。その値は環境から、アクティベーションごとに一度与えられます。ヘッダーに _入力元_ の語、名前の前に入る矢印、**左**端に縦のバー（環境側です。設計の中の何もそれに値を送りません）、出力ソケット 1 つ、入力ソケットなしで描かれます。破線でも _宣言済み_ でもありません。欠けているものは何もないのです。実際の製品で何がその値を与えるか——センサー、ボタン、アナログ線——は配備の事柄であって、キャンバス上の印ではありません。入力元に数式を与えれば、設計の中で計算される通常の関係になります。

**物理出力**はシンクです。名前と右側の語を持つ色付きのヘッダー——設計が完成する前に駆動しなければならない出力には _必須_、あるいはそれを上書きする状態（_ドメインなし_、_競合_、_不正_）。受け取るコンセプト名付きの入力ソケット 1 つ。右端にタイミングドメイン。右側に縦のバー——そこから何も流れ出ません。

選択中のノード（上の `dimByTilt`）はアクセントカラーで縁取られます。キャンバス上の他の何もその色を使いません。

コンポーネントを組み合わせるプロジェクトには、**インスタンスノード**（ポートごとに 1 行、本体にコンポーネント名）と、**振る舞い領域**または折りたたまれた**振る舞いボックス**も表示されます。[システムプロジェクト](../../../../docs/user-guide/studio/system-projects.md) を参照。

すべてのノードに場所があります。あなたが配置していないノード——コードビューやコードエディタで作られたもの、古いプロジェクトの初回オープンで生じたもの——は自動で配置されます。その種類の列（左にコンセプト、中央に関係、右に出力）で、読み取るもの・生成するものの横、すでにあるものの下に。あなたが配置したものは動きません。好きな場所にドラッグしてください（[設計・コード・分割](code-view.md)）。

## ジェスチャ

| 操作 | 結果 |
| ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 空のキャンバスをドラッグ | パン |
| スクロールホイール / ピンチ | ポインタを中心にズーム |
| Home または ⌘0 | 設計全体を表示 |
| ノードをクリック | 選択する（インスペクターが追従） |
| ⇧-クリック | 複数選択に加える / から外す |
| 空のキャンバスで ⇧-ドラッグ | 矩形選択 |
| ノード本体をドラッグ | 移動する。離すと位置が保存される（設計の変更ではない） |
| 出力ソケットから入力ソケットへドラッグ | リンクを作る。ドラッグ中、受け入れられるすべてのソケットにハローが、互換性のないソケットには禁止カーソルが表示される |
| 接続済みの入力ソケットから引き離し、空のキャンバスで離す | 切断 |
| ドラッグ中のリンクを空のキャンバスに落とす | 何も起きない（ノードは作られない） |
| ⌫ / Delete | 選択を削除する。使用中のコンセプトは使用者を挙げたバナーとともに拒否される |
| コンセプトまたは関係ノードをダブルクリック | その場で名前を変更する（出力はインスペクターで名前を変更。インスタンスはソースを開く） |
| 右クリック | コンテキストメニュー（下記） |
| ライブラリタブの行をキャンバスへドラッグ | そのコンセプトを落とした位置に挿入する。名前が編集状態で開く |

## コンテキストメニュー

空のキャンバスで：**コンセプトを追加 ▸**——_最近_、_入力_、_出力_、最もよく使う 3 つのカテゴリ、_その他…_（ライブラリタブを開く）。**入力元を追加 ▸**——標準の入力元（_温度センサー_、_傾きセンサー_、…）と、設計にすでにあるコンセプトの上に入力元を作る _新しい入力元…_。**インスタンスを追加 ▸** _コンポーネント_ と**新規振る舞いグループ**。

ノード上で：**名前を変更**、**削除**。関係ではさらに**振る舞いとしてグループ化**、**グループに追加 ▸**、**… から外す**。インスタンスでは**ソースを編集**。振る舞いでは**折りたたむ** / **展開**、**再利用可能なコンポーネントとしてパッケージ化…**、**グループ解除**。

## キャンバスが決して示さないもの

下書きの数式（入力したが追加していない数式はキャンバス上の何も変えません。ステータス行が数えます）、値（シミュレートページにあります）、識別子や型名（説明にあります）。
