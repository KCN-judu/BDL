# インスペクター

インスペクター（右）は選択中のオブジェクトを、設計者の語彙で、セクションからなるフォームとして示します。すべてのフィールドはコンパイラが受け入れる編集であり、インスペクターに飾りはありません。何も選択されていないときは、何を選択できるかを述べます。

セクションの下で、**最後の変更**は直近の編集の帰結を _他の_ オブジェクトについての一文として述べます——_他に再検査が必要なものはありません。_ または _この変更は dimByTilt、warmPulse に影響します。それらは再検査されます。_——そして折りたたまれた**説明**が形式的な詳細を保持します。

## コンセプト

| セクション | フィールド | 備考 |
| ----------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| **意味** | 名前、意味 |  |
| **値** | 量 / オン/オフ / 個数 / 後で決める。単位（量の種類の一覧、記号は独自の列） | 値の形式を初めて選んでも何も再検査されない。選んだものを変えると、どの関係を再検査するかが示される |
| **関係** | _生成元_、_使用元_ | 名前はその関係を選択するリンク |
| **削除 …** |  | 使用中は無効。使用者はボタンの下に列挙される |

## 関係

| セクション | フィールド | 備考 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| **意味** | 名前、意味 |  |
| **読み取り** | コンセプトのグリフ付きチップ、削除可能。追加用のポップアップ | 編集。依存するものは再検査される |
| **生成** | グリフ付きのポップアップ | 編集 |
| **関係** | 数式フィールドとその判定行。_定義を追加_ / _定義を保存_ / _元に戻す_ / _定義を外す_。フィールドの下に検出項目 | [数式エディタ](formula-editor.md) を参照 |
| **タイミング** | _更新ドメイン_——ドメイン、または _任意のタイミングドメイン_。タイミングの検出項目 | [タイミング](../../../../docs/user-guide/concepts/timing.md) を参照 |
| **駆動先** | この値が駆動する出力、またはなし。接続の検出項目 | 入力のない関係だけが駆動できる |
| **修正** | この関係の検出項目に対してツールが提供する操作。準備できていればボタン、選択が必要ならポップアップ、阻まれていればその理由 | 通常の、取り消し可能な編集として適用される |
| **削除 …** |  |  |

関係にはさらに、_グループ … に属しています_ と _グループを表示_ リンク、ポートにバインドされているときは _… から値を取ります_ と _バインディングを表示_（_切断すると、この関係を自分で定義できます。_ 付き）、そしてコンポーネントのソース内ではそれが裏付けるポート（_requires_ / _provides_ / _parameter_）が表示されることがあります。ポートはコンポーネント自身のインスペクターから宣言します。

## タイミングドメイン

タイミングドメインにはインスペクターページがありません。サイドバーでその場で名前を変更し、未使用の間はそこで削除します。その意味は、そこで _更新される_ 関係と出力にあります。

## 振る舞い、コンポーネント、インスタンス、バインディング

これらには独自のインスペクターがあります。[システムプロジェクト](../../../../docs/user-guide/studio/system-projects.md) が説明します。

## 説明

すべてのインスペクターの末尾にある開示部。オブジェクトの識別番号、形式的なインターフェース、数式を持つ関係なら推論された型と Core 項、状態語、各検出項目の背後にある診断コードと技術的なテキスト、リビジョン、そして最後の変更の種類（_精緻化_ / _編集_）と無効化したものを示します。Studio でコンパイラの語彙が現れる唯一の場所です。その上の何もこれに依存しません。
