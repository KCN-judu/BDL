# examples

Checked-in projects that open in Studio (Open Project…) and are kept faithful by
tests.

| Project             | Demonstrates                                                                                                                                                                                                                                                                                                                                        | Kept by                                                                                                                                                                                                                                                    |
| ------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `smart_lamp/`       | `Tilt` and `AmbientLight` in (two unresolved inputs on the `interaction` domain), `Brightness` out; `dimByTilt`, `adaptBrightness` and the driver `brightness = adaptBrightness(dimByTilt(tilt), ambient)`; one required output _Light Output_ realised by a `pwm_channel` device — Design → Simulate → Deploy                                      | `crates/bdl-compiler/tests/examples.rs` (authored from ops, analysed, simulated, placed, byte-identical to the files); `apps/studio/test/smart_lamp_e2e_test.dart` (the same walk through Studio's reducer against `bdld`)                                 |
| `breathing_beacon/` | No Source: the dynamics live in `delay` cells — a triangle-wave breath, a gamma curve, a first-order lag and a Schmitt trigger (percent levels), out to two `pwm_duty8` pins (D9, D10) and a `gpio_level` pin (D13) of the Arduino Nano; _Feasible_ as shipped, so it builds and flashes as is                                                      | `crates/bdl-compiler/tests/example_breathing_beacon.rs` (loaded from the text on disk: the ladder, the reference simulation over one breath, deployment on the Nano, the firmware core's duties on the host, the AVR ELF where the toolchain is installed) |
| `sensor_station/`   | Three analog Sources through catalogue curves — a 10 kΩ thermistor (A1, `adc_ntc10k_b3950`), a photoresistor (A0, `adc_ldr_gl5528`), a trim pot (A2, `adc_percent`) — and three outputs: a gamma-corrected night light (D9, `pwm_gamma8`), a fan with inertia (D10) and a hysteresis overheat lamp (D13); _Feasible_ on the Arduino Nano as shipped | `crates/bdl-compiler/tests/example_sensor_station.rs` (the deployment, the firmware core over ADC counts computed from the parts' physics, the AVR ELF where the toolchain is installed)                                                                   |
