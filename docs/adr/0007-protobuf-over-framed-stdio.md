# ADR-0007: Protobuf messages over framed child-process stdio

**Status**: accepted (2026-09-15)

## Context
The Studio ↔ bdld protocol must be strongly typed, versioned, and not
hand-maintained twice. The transport must be reliable on desktop without
weeks of IPC design.

## Decision
Messages are Protocol Buffers (`bdl.proto`, one source of truth). Rust code
is generated at build time with `prost` + `protox` (no `protoc` needed);
Dart code is generated by `just proto` and checked in, with CI diffing it.
Transport v0.1 is child-process stdio with 4-byte length-prefixed frames;
protocol and transport are separate modules so loopback TCP can be added
later. Protocol version `0.1.0`; equal major ⇒ compatible.

## Consequences
* No duplicate Dart/Rust message definitions.
* Logging must go to stderr; stdout is the channel.
* Full-projection events in v0.1; deltas are an additive change.
