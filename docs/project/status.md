# Implementation status

What exists at repository HEAD, per area. _Implemented_ means present and
exercised by the named test; it does not mean released, and it never means
formally proved (see [formal-correspondence.md](formal-correspondence.md) for
that). Updated when work lands or is removed; the [roadmap](roadmap.md) says
what is next, the [change records](../changes/README.md) say what changed and
when.

**Snapshot:** 2026-09-21, at protocol 0.28. The most recent work, newest first:
the authoring UX slice (the Standard Library as 22 value categories and the
concept sheet that names a concept before creating it, with the compiler's units
shown as a fact; the Formula view as typed structure — a caret read off the
compiler's tree, keys that are text edits or compiler actions, completion while
typing, fractions, branch diagrams, `match` / `let` / `delay` / `sync` as
structure; a saved formula unfolded on its node; ADR-0041, ADR-0042; 0.28),
composite units and the Formula view's structure (a unit expression after a
number — `180 deg per s`, `9.81 m per s^2`, `1 N * m` — as a derived surface
over the registered atoms with the dimension and scale the algebra gives; the
compiler-owned value categories and unit candidates; the projection with roles,
locals and the structured `match` / `let` / rule / `delay` / `sync` forms,
structural carets, keyboard insertion, completion at a caret, signature help and
the saved-formula render; ADR-0040; 0.27), the first hardware demo end to end
(the daemon builds the firmware stage by stage and flashes the Raspberry Pi Pico
over its own bootloader, an image whose identity is what it was built from is
never flashed stale, the Deploy page ends in Build · Flash · Observe with one
action per state, the Button → Lamp demo as two templates on the Welcome page;
ADR-0039; 0.26), the Source half of the platform adapter (a device provides a
Source through a catalogue profile — `bdl-catalogue`, two GPIO line providers,
the provision judged in four inspectable parts, the RP2040 firmware reading the
line before each tick, `Button → rule → Lamp` as one firmware; ADR-0038; 0.25),
the first embedded platform adapter (raw commands reach a Raspberry Pi Pico over
Embassy: `bdld compile --target rp2040_pico`, an explicit numeric policy at the
boundary, the firmware cross-compiled in CI; ADR-0037), output realization (a
deployment-chosen profile whose pure encoder lowers the output's value to a raw
command; three-judgment admissibility; ADR-0036; 0.24), the Source sheet (a
Source is created over a chosen concept — existing, or new in one transaction;
the Standard Library's Source items are presets; 0.23), the Code view as an IDE
surface (completion, hover, definition, references and format from the one IDE
service; 0.22), semantic highlighting (ADR-0035; 0.21), the derived relationship
role stated by the daemon (ADR-0032 amended; 0.20), the unapplied-rule finding
(0.19), reference edges (ADR-0034; 0.18). Every milestone before that is in
[changes/history/milestones.md](../changes/history/milestones.md) and
[changes/unreleased/](../changes/unreleased/); the protocol's versions in
[changes/history/protocol-versions.md](../changes/history/protocol-versions.md).
